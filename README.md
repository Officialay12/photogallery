
# 📷 Photo Gallery Web App  

A beautiful, responsive **photo gallery** built with HTML, CSS, and JavaScript. Showcase your images in a sleek grid layout with lightbox previews and smooth animations.  

#([woo.jpg])  


## 🌟 Features  
- **Responsive Design**: Works on mobile, tablet, and desktop.  
- **Lightbox Preview**: Click thumbnails to enlarge images.  
- **Filter by Category**: Organize photos with tags (e.g., Nature, Travel).  
- **Smooth Animations**: CSS transitions for a polished feel.  
- **Easy to Customize**: Add your own images in seconds!  

## 🛠️ Technologies Used  
- HTML5, CSS3 (Flexbox/Grid)  
- Vanilla JavaScript (for lightbox & filtering)  

## 🚀 Quick Start  
1. **Clone the repo**:
2. **Open `photo.html`** in your browser.  
3. **Add your photos**: Replace images in `/assets` and update `data.json` (if applicable).  

## 🔧 Customization  
- Edit `photo.css` to change colors/fonts.  
- Modify `photo.js` to adjust animation speeds or filtering logic.  
- Add/remove images by editing the HTML or JSON file.
